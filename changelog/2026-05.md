# Changelog — May 2026

## 2026-05-11 — Suno Style Box 1,000 Character Hard Limit

### Summary
Added explicit documentation of Suno's 1,000 character Style box ceiling. Previous guidance ("100–200 words for production-grade prompts") consistently exceeded the actual UI limit, producing silently truncated prompts. Updated three locations to use character-count targets instead of word counts, with the platform limit as the canonical ceiling.

### Files Updated

- `models/suno/advanced-prompting.md`
  - Added new "Hard Limits — Style Box (1,000 Character Ceiling)" section immediately after the Two-Box Rule. Includes target table, rationale for char-over-word counting, five rules for staying under limit, and truncation symptoms checklist.
  - Updated Best Practices #8 to reference the 1,000 char hard ceiling and 600–900 char safe target.

- `shared/prompt-framework.md`
  - Updated "Prompt Length Guidelines" table to add a "Hard limit" column with explicit char counts.
  - Replaced word-count-only guidance for Suno with char counts.
  - Added a `model:suno` callout pointing to the Hard Limits section in advanced-prompting.md.

### Rationale
The Suno UI enforces a hard 1,000 character cap on the Style box. Prompts above this are truncated at submission, almost always at the tail of the prompt where negatives sit. Negatives are the highest-character-cost layer, so truncated prompts both fail to exclude what they intended AND include the elements the writer was trying to remove.

Word-count guidance compounds the problem because mix-engineer vocabulary uses long compound noun phrases (`heavy rumbling 808 sub-bass`, `late-2020s Atlanta trap production`, `precise instrument separation`). Average character-per-word for this vocabulary runs 7–9 chars once spaces are included. A 200-word prompt routinely lands at 1,400–1,600 characters — 40–60% over the limit.

### New Targets

| Constraint | Value |
|---|---|
| Hard ceiling (platform-enforced) | 1,000 chars (~150 words) |
| Safe production-grade target | 600–900 chars (~90–140 words) |
| Tight target (loop/electronic) | under 500 chars (~75 words) |
| Minimum viable | 150 chars (~25 words) |

### Validation
Audit ran against three recent production prompts. All three exceeded 1,000 chars (1,150, 1,250, 1,310). All three were producing AI output that included excluded elements, consistent with negative-truncation. Re-running each at ~800 chars produced correctly excluded output.

### Out of Scope
- Lyrics box character limit (separate field with its own constraint, not changed in this update)
- Gemini/Lyria prompt length (no equivalent hard ceiling documented for those platforms)
